一｜圣泉不是一个可以合并为同一状态的文件夹

《圣泉传说》并非一个将所有天马行空的想法胡乱塞进同一根目录的散装模组，而是一个架构清晰、边界森严的模块化游戏工程矩阵。主模组本体（创意工坊项目 3381939779，工坊显示 V3.1.6.3）承担主要玩法。中文工坊与主模组仓库均显示 V3.1.6.3，主模组描述文件的显示名已同步，并声明支持 CK3 1.21.*。这不代表独立混沌扩展或旧存档已经通过实机验收。主模组涵盖从悬圃基建、仙女征召、学院骑士团、熔炉宝库到阿斯塔特五大职业与龙泉天朝军势的全部实装正典。

站点素材和公告的版本号不等于工坊实际安装内容；本站源码引用依已审查的 GitHub 版本，未直接验证订阅者本地文件。

二｜开发存在，不等于正式可用

矩阵的第二层是独立扩展《圣泉：混沌扩展》（sq_chaos_addon），定位为“开发候选与专项测试包”，正在开发并测试周期裂隙入侵、恐虐极恶骑士、祭司净化等玩法，完整旧档和复杂战争结果尚未游戏验收；第三层是可选的《阿斯塔特铠甲》外观子模组，通过同名覆盖 sq_astartes_standard_armor_trigger 为修士披挂陶钢动力甲；第四层则是已完全从主干退役的《旧混沌档案》（m14），仅作技术演进考据。

区分各个内容包的生命周期，绝不将开发中的实验特性与主干正式版混为一谈。

Story, choices and consequences

The Chinese Workshop listing and the repository identify the core mod as V3.1.6.3. The descriptor gives the same display name and targets CK3 1.21.*. This does not certify the Chaos expansion or existing saves. The independent Chaos expansion remains a separate test candidate with an older base-mod dependency. The Astartes armour add-on has its own release list.

The Chaos chapters on faith, invasions, champions, corruption and artwork describe parts of one independent expansion, not five different mods to subscribe to. Historic main-mod Chaos material remains useful as an archive, but its old instructions should not be applied to the current expansion.

For each package, follow its actual Workshop requirements and versions. A published label is not proof that every combination has undergone hands-on game testing. Current feature guides describe how a system works; release announcements record what changed at a particular point in the project's history.

English long-form copy has not yet received the same final source-alignment pass as the Chinese edition.
