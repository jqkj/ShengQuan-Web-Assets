一｜没有一份能够通吃所有组合的补丁

打造一个庞大而稳定的中世纪魔改世界，严谨的模组加载顺序与兼容规范是永恒的基石。《圣泉传说》主模组（创意工坊 ID: 3381939779，工坊已发布 V3.1.6.2；请核对工坊当前支持的游戏版本与依赖）包含了深度的宗族、宝物、特质与GUI界面系统。将任意补丁视为“通吃所有组合”的万能解药是极具破坏性的误区；一个补丁通常只针对特定游戏版本中发生冲突的几项定位文件生效，盲目覆盖往往会导致更多暗病。

开始修改之前，先记录《十字军之王3》游戏版本、圣泉主模组版本、关联子模组版本与其他模组的启用情况。只有当补丁说明明确列出你实际使用的组合，才应继续按照所述位置处理。这里的“兼容”意味着对明确问题有过适配，不是对所有第三方模组作出保证。

二｜安装与撤销同样重要

标准安装规范要求：首先在启动器中建立清晰的加载层级——【CK3 原版底层】->【系统框架与大型汉化】->【圣泉传说主模组（338）】->【独立子模组（混沌扩展、铠甲外观包）】->【专用兼容补丁】。

在应用任何手动覆盖补丁前，务必先对相关文件及重要存档进行离线备份，并在文本中记录修改的原始路径与撤销步骤。当主模组发布小版本热修复时，应主动检查旧补丁是否已被官方吸收，及时移除失效文件。

Story, choices and consequences

Before combining Sacred Spring with another mod, check whether the two change any of the same clothing, character eligibility or interaction-category files. The optional compatibility patches provide targeted adjustments for known combinations; they do not claim that every loadout is universally safe. Pick only the patch that matches the mods you actually installed.

Exit the game, back up the original target file and follow the corresponding path inside the main-mod folder. There are separate patch files for EPE, a character-pack Knight eligibility check and Princes of Darkness interaction categories. A patch must be copied deliberately; the presence of files in a package does not mean they have overwritten your installation.

Keep a rollback copy and verify the combination again after either mod is updated. The older AGOT dragon ageing patch is historical and not part of the current supplied set. Current Workshop requirements take precedence over the mere existence of an old compatibility note.

English long-form copy has not yet received the same final source-alignment pass as the Chinese edition.

玩法与规则What the compatibility patch contains

有些领主带着另一套衣装来到泉边，有些骑士来自不同的故事。兼容补丁为这些相遇整理必要的接口，让你能按自己的模组组合选择适配方式。

当前版本随包提供三组适配文件：

  • EPE 服饰：调整共同使用时的圣泉人物服饰配置。
  • 幻萌角色骑士资格：将相关人物条件接入骑士资格判断。
  • 黑暗王子交互分类：让两边的角色交互分类能够并置。

只需选择与你的组合对应的补丁，应用前备份目标文件。文件随包提供，不会自动替你完成覆盖；两边模组更新后，也需要重新核对适用范围。

旧版 AGOT 龙族免老年病补丁已不在当前版本中，本页仅保留这条历史说明。

These optional files help particular mod combinations coexist. They are not a universal compatibility guarantee. The current package documents three supported patch combinations: EPE portrait clothing, a special character pack’s Knight eligibility, and Princes of Darkness interaction categories. Apply only what your current loadout needs, and back up target files first. The old AGOT dragon-ageing patch is no longer included.

The user must copy files manually; simply subscribing to the main mod does not overwrite the target files automatically.
