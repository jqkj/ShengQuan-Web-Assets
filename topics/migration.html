一｜更新之前，先记住当前的样子

一个延续数十代人、历经百年开拓的王朝存档，是玩家最为珍视的游戏资产。在跨越游戏大版本或圣泉模组迭代时，许多崩溃与数据丢失并非源于底层逻辑本身，而是由于跳跃式覆盖破坏了正在执行的事务堆栈。《圣泉传说》在 V3.1.6.1 的重构中引入了严格的向下兼容规范：旧版已退役的混沌入侵调用在主模组中被包装为空存根（hundun_dlc03_on_action = { }），确保老存档中的定时回调平稳消化而不会弹出致命红字。

原版发布了新内容，不代表圣泉已经完成对应适配；模组拥有新的开发分支，也不意味着它已经全部进入正式发布。迁移前先辨认自己到底启用了哪些内容，远比盲目寻找一份“万能兼容顺序”更有效。

二｜按实际变化检查，而非只看版本号

进行版本迁移前，请务必执行“五项健康核对清单”：第一，确认君王仍真实持有「圣泉悬圃核心」宝物（未被继承分割）；第二，检查药剂师是否有正在进行中但未结清的十八重塑手术（建议在升级前全部完成并点击结束）；第三，检查圣泉功业榜是否处于暂停或进行中委托，确认点数归属；第四，核对骑士团与学院学籍；第五，确认五大阿斯塔特职业特质与血脉未发生属性畸变。

做好离线归档，方能让古老传奇在新版本中无缝延续。

Story, choices and consequences

A long-running dynasty is worth a backup before a major change. Record the game version, Sacred Spring main mod, Chaos expansion, armour add-on and other mods in your playset. Keep a separate save copy so a changed ruleset cannot silently erase your only campaign history.

Compatibility files serve specific combinations. Confirm exactly which patch and destination apply before overwriting anything, and keep the replaced file for rollback. The documented baseline for the main mod is V3.1.6 with CK3 1.20.* support; your current Workshop listings should be consulted at installation time.

A future base-game update or an announcement of its date does not prove the Sacred Spring mod has already been adapted. Read the actual support notes after each release, and treat older previews as historical records instead of promised compatibility.

更新前记录版本与组合Record versions and your mod combination

Write down the CK3, main mod, armour and Chaos expansion versions and any other loaded mods. Back up your save separately. The documented main-mod baseline is V3.1.6 / CK3 1.20.*; the Workshop’s current requirements govern what to install.

补丁只对明确的模组组合使用Use only matching patches

适配文件不是通用兼容开关。核对你实际使用的模组、文件路径与安装方法，备份被替换内容，并保留撤销方法。详细操作见兼容补丁与安装。

A compatibility patch is not a universal switch. Confirm the specific combination, target file and installation method; back up overwritten files and keep a rollback plan. Detailed compatibility guide.

原版更新计划不代表模组已经适配A base-game update does not prove mod support

原版预告与计划发布时间不能作为圣泉已完成适配的证明，也不应直接改写当前功能名称。支持范围改变后，应以对应发布说明和工坊要求为准。旧预告与现行兼容性应分开判断；可查阅已收录的版本记录，并以当前工坊说明为准。

A previewed CK3 release date is not a promise of immediate Sacred Spring compatibility. Follow published support notes after a release; consult the release chronology for recorded changes; current support follows the Workshop requirements.
